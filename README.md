# 👣 FOOTSTEPS
A short choice based terminal game


**FOOTSTEPS** is a short text-based interactive horror game written in Python.

The player wakes up after hearing mysterious footsteps inside a house and must make a series of decisions in an attempt to escape. Every choice affects the outcome, leading to one of several possible endings.

This project was created to practice building an interactive program using loops, conditional statements, and branching story paths.

## Gameplay

The game begins with a simple main menu where the player can either start the game or exit.

Once the game starts, the player is presented with a sequence of choices. Depending on the decisions made, the story follows different paths and eventually reaches one of four unique endings.

The focus of the game is simple decision-making rather than fast reflexes or complex mechanics.

---

## Features

* Interactive text-based horror experience.
* Menu-driven interface.
* Multiple story branches.
* Four unique endings.
* Input validation through menu options.
* Replay-friendly command-line gameplay.
* Clean console formatting using line breaks for readability.

---

## Endings

The current version contains **four possible endings**:

* 🏃 Escape immediately by running toward the light.
* 🏃 Escape after hiding and making the correct decisions.
* 🚪 Be caught after remaining hidden for too long.
* 👤 Be caught after attempting to hide again while being chased.

Each ending is determined entirely by the player's choices throughout the game.

## What I Learned

This project gave me hands-on experience creating a branching story where different choices lead to different outcomes.

Compared to my earlier projects, this one required planning the flow of the program before writing the code. I learned how to organize multiple decision paths and connect them into a complete game using nested conditional statements.

It also reinforced my understanding of keeping a program running with loops until a specific ending or exit condition is reached.

---

## Current Limitations

* Story is limited to a single scenario.
* Uses nested conditional statements, which become harder to manage as the story grows.
* Does not include a restart option after completing an ending.
* No save/load functionality.
* Player choices are limited to numbered menu selections.
